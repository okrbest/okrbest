# Contract: 네비게이션 UI 동작 계약

**Date**: 2026-10-08 | **Plan**: [../plan.md](../plan.md) | **Spec**: [../spec.md](../spec.md)

서버 API 변경이 없으므로 계약은 UI 동작과 플러그인 접점으로 정의한다.

## 레일 (전 화면 공통)

| 요소 | 조건 | 동작 |
|---|---|---|
| 현재 팀 버튼 (최상단) | 항상 | 클릭 → 팀 목록 메뉴 오픈. aria-label에 팀 이름 포함 |
| Channels 버튼 | 항상 | 클릭 → 현재 팀 채널 화면 복귀. Channels 화면이면 활성 강조 |
| 제품 버튼 (등록 순) | 제품 레지스트리에 있을 때만 | 클릭 → `switcherLinkURL` 이동. 해당 제품 경로면 활성 강조. 아이콘은 `switcherIcon`(문자열이면 glyphMap, ReactNode면 그대로), 라벨은 `switcherText` |
| 플러그인 슬롯·프로필 버튼 | 기존 조건 | 기존 동작 그대로 (프로필은 최하단 고정 유지) |
| peek | 채널 사이드바 접힘 + 레일 호버 | 기존 동작 그대로 |

접근성: 모든 버튼은 role=button/link + 이름(aria-label 또는 가시 라벨).
활성 강조는 색 외에 시각적 구분(예: 표시자)을 하나 더 가진다.

## 팀 목록 메뉴 (공용 — 레일·팀명 드롭다운 동일)

| 항목 | 조건 | 동작 |
|---|---|---|
| 내 팀 각각 | 가입한 팀 | 클릭 → 그 팀으로 전환. 현재 팀에 체크 표시 |
| 다른 팀에 가입 | 기존 권한 조건(가입 가능 팀 존재 등) | 기존 팀 가입 화면으로 |
| 새 팀 만들기 | 기존 `CREATE_TEAM` 권한 조건 | 기존 팀 생성 화면으로 |

정렬: 저장된 사용자 팀 정렬 순서, 없으면 표시 이름순 (기존 레일 정렬 로직과
동일 판정).

## 팀명 드롭다운 (sidebar_team_menu)

위에서 아래로: ① "내 팀" 섹션(팀 목록 메뉴) → ② 기존 팀 관리 항목(초대·팀
설정·구성원 관리·팀 나가기 등, 변경 없음) → ③ 이전된 관리 섹션 — 시스템
콘솔(관리자 도구)·통합·사용자 그룹·앱 마켓플레이스·앱 다운로드·OKR.Best 정보.
③의 각 항목 노출 조건은 기존 product switcher 메뉴의 조건과 **동일 판정**이어야
한다 (권한·서버 설정·라이선스 분기 포함).

## 상단 좌측 (global header)

- product switcher(드롭다운 버튼·현재 제품 브랜딩) 제거.
- history 뒤로/앞으로 버튼만 잔존, 위치·동작 변경 없음.
- 어떤 화면에서도 `#product_switch_menu` 요소가 존재하지 않는다.

## 플러그인 접점 (무수정 계약)

- 본체는 `registerProduct`로 등록된 값만 읽는다. 등록 인터페이스·순서·기본값을
  바꾸지 않는다.
- `showTeamSidebar: true`인 제품 화면에서 개편된 레일이 그대로 표시된다.
- 팀 전환은 본체 현재 팀 변경만 수행한다 — Boards의 양방향 동기화, Playbooks의
  현재 팀 직독 동작을 신뢰하며 본체가 플러그인 내부 라우팅에 개입하지 않는다.

## i18n

새 키(예시 — 구현 시 확정): 레일 영역 라벨(`team_sidebar.productRail.*`),
팀 목록 섹션 제목(`sidebarLeft.teamMenu.myTeams`), 레일 팀 버튼
aria-label. 이전되는 관리 항목은 기존 키(`navbar_dropdown.*`) 재사용 — 신규
번역 불필요. 모든 신규 키는 en/ko 동시 추가.
