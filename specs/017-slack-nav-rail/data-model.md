# Data Model: 좌측 네비게이션 Slack식 재구성

**Date**: 2026-10-08 | **Plan**: [plan.md](./plan.md)

서버·DB·preference 저장 변경이 없다. 다루는 데이터는 전부 클라이언트가 이미
갖고 있는 상태의 **읽기**다.

## 읽는 데이터

| 데이터 | 원천 | 쓰임 |
|---|---|---|
| 제품 목록 | 플러그인 제품 레지스트리 (`ProductComponent[]`) | 레일 제품 버튼 생성 (아이콘·이름·이동 주소) |
| 현재 제품 | 현재 경로 ↔ 제품 `baseURL` 대조 (`useCurrentProductId`) | 레일 활성 강조 |
| 내 팀 목록 | 팀 엔티티 + 멤버십 셀렉터 | 팀 목록 메뉴 |
| 팀 정렬 순서 | 기존 사용자 preference(팀 정렬) — 읽기만 | 팀 목록 정렬 |
| 현재 팀 | Redux 현재 팀 | 레일 팀 버튼 표시·전환 기준 |
| 권한/설정 | 기존 권한 셀렉터·서버 설정 | 관리 메뉴 항목별 노출 조건(이전 전과 동일) |

## 파생 상태 전이

```text
[제품 전환] 레일 버튼 클릭 → 라우터 이동(switcherLinkURL)
            → 현재 제품 재계산 → 레일 강조 이동
[팀 전환]   팀 목록 항목 클릭 → 현재 팀 변경(기존 팀 이동 경로 재사용)
            → 채널 화면: 그 팀 채널로 이동
            → Boards: 플러그인이 MM store 구독으로 자체 추종 (플러그인 무수정)
            → Playbooks: 현재 팀을 직접 읽어 갱신 (플러그인 무수정)
```

## 컴포넌트 단위 (신설/개편)

| 단위 | 하는 일 | 입력 | 의존 |
|---|---|---|---|
| `RailTeamButton` (신설) | 현재 팀 아바타 표시, 클릭 시 팀 목록 메뉴 오픈 | 현재 팀 | TeamListMenu |
| `RailProductButton` (신설) | 아이콘+라벨 렌더, 활성 강조, 클릭 이동 | 제품 1건, 활성 여부 | compass glyphMap, 라우터 |
| `TeamListMenu` (신설, 공용) | 내 팀 목록 + 가입/생성 항목, 현재 팀 체크, 클릭 전환 | 내 팀 목록·현재 팀 | Menu 위젯 |
| `TeamSidebar` (개편) | 위 셋을 조립. peek·프로필·플러그인 슬롯 유지 | — | 기존 레일 골격 |
| `SidebarTeamMenu` (개편) | 상단 "내 팀" 섹션(TeamListMenu) + 하단 이전 관리 메뉴 섹션 | — | TeamListMenu |
| `LeftControls` (개편) | product_menu 제거, history 버튼만 | — | — |

각 단위는 독립 테스트 가능해야 한다 — TeamListMenu는 레일·사이드바 어느 쪽
문맥 없이도 렌더·전환이 검증된다.
