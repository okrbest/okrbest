# Feature Specification: 좌측 네비게이션 Slack식 재구성

**Feature Branch**: `017-slack-nav-rail`

**Created**: 2026-10-08

**Status**: Draft

**Input**: User description: "좌측 상단 Channels 버튼의 product switcher 메뉴 대신, Boards·Playbooks 진입 버튼을 Slack의 기능 버튼처럼 좌측 레일에 세로 나열한다. 팀 선택은 레일의 팀 버튼 나열 대신 Slack처럼 드롭다운에서 고른다. product switcher에 있던 관리자 도구·통합·사용자 그룹·OKR.Best 정보 메뉴는 팀명 드롭다운으로 옮긴다."

## 배경

지금 제품 전환(Channels ↔ Boards ↔ Playbooks)은 좌측 상단 Channels 버튼을
눌러 드롭다운을 열어야 보인다. 두 번 클릭해야 하고, 다른 제품이 있다는 사실
자체가 드러나지 않는다. 팀 전환은 좌측 레일에 팀 버튼을 세로로 나열하는데,
팀이 많아지면 레일이 길어지고 Slack에 익숙한 사용자의 기대(워크스페이스
드롭다운)와 어긋난다.

이 기능은 두 축을 맞바꾼다 — **자주 쓰는 제품 전환은 항상 보이는 레일
버튼으로, 가끔 쓰는 팀 전환은 드롭다운으로**. Boards·Playbooks 화면에서는
채널 사이드바가 보이지 않으므로, 팀 전환 진입점은 레일 상단의 현재 팀
버튼으로도 제공해 어느 화면에서나 팀을 바꿀 수 있게 한다.

[014-slack-design-benchmark](../014-slack-design-benchmark/spec.md)는 "레이아웃
골격(팀 레일·사이드바·본문 5단 구조) 유지"를 전제로 색·타이포만 다뤘다. 이
기능은 그 전제를 바꾸는 후속 작업이다 — 골격 중 팀 레일의 역할을 재정의한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 레일에서 제품을 한 번에 오간다 (Priority: P1)

사용자가 좌측 레일에서 Channels·Boards·Playbooks 버튼(아이콘+이름)을 본다.
버튼 하나를 클릭하면 해당 제품 화면으로 바로 이동하고, 지금 어느 제품에 있는지
레일에서 강조로 표시된다. 레일은 채널 화면과 제품 화면 어디에서나 보인다.

**Why this priority**: 이 기능의 핵심 가치다. 제품 전환을 "숨은 메뉴 2클릭"에서
"보이는 버튼 1클릭"으로 바꾸는 것이 목적이며, 이것만 동작해도 가치가 성립한다.

**Independent Test**: Boards·Playbooks 플러그인이 켜진 서버에서 로그인 후 레일
버튼 구성·강조·클릭 이동을 확인한다. 플러그인을 끈 서버에서는 해당 버튼이
나타나지 않는 것도 확인한다.

**Acceptance Scenarios**:

1. **Given** Boards·Playbooks 플러그인이 활성화된 서버에 로그인했다, **When**
   채널 화면을 본다, **Then** 좌측 레일에 Channels·Boards·Playbooks 버튼이
   세로로 나열되고 Channels가 현재 제품으로 강조된다.
2. **Given** 채널 화면에 있다, **When** 레일의 Boards 버튼을 클릭한다,
   **Then** Boards 화면으로 이동하고 레일의 강조가 Boards로 바뀐다.
3. **Given** Boards 화면에 있다, **When** 레일의 Channels 버튼을 클릭한다,
   **Then** 보던 팀의 채널 화면으로 돌아온다.
4. **Given** 플러그인이 모두 꺼진 서버다, **When** 레일을 본다, **Then**
   Channels 버튼만 있고 빈 자리나 깨진 버튼이 없다.

---

### User Story 2 - 팀을 드롭다운에서 고른다 (Priority: P1)

여러 팀에 가입한 사용자가 채널 사이드바 상단의 팀명을 클릭하면 드롭다운에
"내 팀" 목록이 보인다(현재 팀에 체크 표시). 다른 팀을 클릭하면 그 팀으로
전환된다. Boards·Playbooks 화면에서는 레일 상단의 현재 팀 버튼을 눌러 같은
목록을 열 수 있다.

**Why this priority**: 레일에서 팀 버튼을 치우는 순간(US1과 같은 변경) 팀 전환
수단이 이것뿐이다. US1과 분리 배포할 수 없는 동반 필수 기능이다.

**Independent Test**: 팀 2곳 이상에 가입한 계정으로 팀명 드롭다운·레일 팀
버튼에서 각각 팀 목록을 열어 전환하고, 1곳만 가입한 계정에서 목록이 1건+팀
가입/생성 항목으로 나오는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 팀 3곳에 가입했고 채널 화면에 있다, **When** 팀명 드롭다운을 연다,
   **Then** 내 팀 3곳이 보이고 현재 팀에 체크가 있다.
2. **Given** 팀명 드롭다운이 열려 있다, **When** 다른 팀을 클릭한다, **Then**
   그 팀의 채널 화면으로 전환된다.
3. **Given** Boards 화면에 있다, **When** 레일 상단의 현재 팀 버튼을 눌러 다른
   팀을 고른다, **Then** Boards가 그 팀의 보드를 보여준다 (화면을 떠나지 않고
   팀만 바뀐다).
4. **Given** 팀 가입/생성 권한이 있다, **When** 팀 목록을 연다, **Then** 기존
   "다른 팀에 가입" · "새 팀 만들기" 항목이 목록과 함께 보인다.

---

### User Story 3 - 관리 메뉴가 팀명 드롭다운으로 옮겨진다 (Priority: P2)

시스템 관리자가 팀명 드롭다운을 열면 기존 팀 관리 메뉴 아래에 관리자 도구·
통합·사용자 그룹·OKR.Best 정보 항목이 보인다. 좌측 상단의 Channels 드롭다운
버튼은 사라지고, 상단 좌측에는 뒤로/앞으로 이동 버튼만 남는다.

**Why this priority**: product switcher를 없애는 정리 작업이다. US1·US2가 끝나야
의미가 있고, 메뉴가 이중으로 보이는 과도기는 허용 가능하다.

**Independent Test**: 관리자·일반 사용자 계정으로 각각 팀명 드롭다운을 열어
항목 노출이 기존 product switcher의 권한 조건과 동일한지, 상단에서 Channels
버튼이 사라졌는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 시스템 관리자로 로그인했다, **When** 팀명 드롭다운을 연다,
   **Then** 관리자 도구·통합·사용자 그룹·OKR.Best 정보 항목이 보인다.
2. **Given** 일반 사용자로 로그인했다, **When** 팀명 드롭다운을 연다, **Then**
   권한이 없는 항목(관리자 도구 등)은 보이지 않고, 기존에 보이던 항목(정보 등)
   의 노출 조건은 그대로다.
3. **Given** 어느 화면이든, **When** 상단 좌측을 본다, **Then** Channels
   드롭다운 버튼이 없고 뒤로/앞으로 버튼만 있다.

---

### Edge Cases

- 팀 1곳만 가입한 사용자 — 레일 팀 버튼과 드롭다운은 그대로 동작하되 목록이
  1건이다. 레일 버튼을 숨기지 않는다(제품 화면에서 팀 가입/생성 진입점 역할).
- 게스트 등 팀 가입/생성 권한이 없는 사용자 — 해당 항목이 드롭다운에서 빠진다
  (기존 권한 조건 그대로).
- 플러그인이 세션 도중 활성화/비활성화되면 다음 화면 갱신 때 레일 버튼이
  나타나거나 사라진다. 비활성화된 제품 화면에 있던 사용자는 기존 동작(채널로
  복귀)을 따른다.
- 모바일 폭 화면 — 기존처럼 레일이 숨는 조건이면 그대로 숨는다. 이 기능은
  데스크톱 폭 레이아웃만 다룬다.
- 레일의 사이드바 peek(채널 사이드바 접힘 상태에서 레일 호버로 임시 공개),
  하단 프로필 버튼, 플러그인 슬롯은 기존 동작을 유지한다.
- 팀 정렬 — 기존 레일의 드래그 정렬은 제거된다. 드롭다운 목록은 기존 정렬
  순서(사용자가 정해 둔 순서, 없으면 이름순)를 따른다. 정렬 변경 UI는 이번
  범위 밖이다.
- 온보딩 투어 중 product switcher 버튼을 가리키는 단계가 있으면 해당 단계를
  제거하거나 레일을 가리키도록 바꾼다 — 깨진 안내가 남지 않아야 한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 좌측 레일은 팀 버튼 나열 대신 제품 버튼을 세로로 나열한다 —
  Channels(항상)와, 활성화된 제품(Boards·Playbooks 등 등록된 제품 전부)을
  등록 순서대로 보여준다. 각 버튼은 제품 아이콘과 이름을 표시한다.
- **FR-002**: 레일은 현재 사용 중인 제품을 시각적으로 강조한다. 제품 버튼
  클릭 시 해당 제품 화면으로 이동하며, Channels 클릭 시 현재 팀의 채널 화면으로
  돌아온다.
- **FR-003**: 레일 상단에 현재 팀 버튼(팀 아바타/이니셜)을 둔다. 클릭하면 내 팀
  목록 드롭다운이 열리고, 팀을 클릭하면 전환된다. 이 버튼은 채널·제품 화면
  어디에서나 보인다.
- **FR-004**: 채널 사이드바 상단 팀명 드롭다운에 "내 팀" 목록 섹션을 추가한다.
  현재 팀에 체크 표시가 있고, 클릭하면 전환된다. 레일 팀 버튼의 드롭다운과 같은
  목록·같은 동작이다.
- **FR-005**: 팀 목록에는 기존 "다른 팀에 가입"·"새 팀 만들기" 진입점이 기존
  권한 조건 그대로 포함된다.
- **FR-006**: product switcher에 있던 관리자 도구·통합·사용자 그룹·OKR.Best
  정보 항목을 팀명 드롭다운으로 옮긴다. 각 항목의 노출 권한 조건은 기존과
  동일하다.
- **FR-007**: 좌측 상단 product switcher(Channels 드롭다운 버튼)를 제거한다.
  상단 좌측에는 뒤로/앞으로 이동 버튼만 남는다.
- **FR-008**: 제품 화면(Boards·Playbooks)에서 팀을 전환하면 해당 제품이 새 팀의
  콘텐츠를 보여준다. 플러그인 코드 수정 없이 동작해야 한다.
- **FR-009**: 레일의 기존 부속 — 하단 프로필 버튼, 플러그인 슬롯, 채널 사이드바
  peek 동작 — 은 그대로 유지된다.
- **FR-010**: 레일 버튼과 팀 드롭다운 항목은 보조기술이 읽을 수 있는 이름을
  가진다(아이콘만 있는 버튼 금지). 새 문구는 한국어·영어로 제공한다.
- **FR-011**: 온보딩 투어 등에서 제거된 product switcher를 가리키던 안내는
  제거하거나 새 레일 버튼을 가리키도록 바꾼다.

### Key Entities

- **제품(product)**: 본체가 기본 제공하는 Channels와, 플러그인이 등록하는
  Boards·Playbooks. 각 제품은 아이콘·이름·진입 주소를 등록해 두며 레일 버튼은
  이 등록 정보만 사용한다.
- **팀**: 사용자가 가입한 작업 공간. 전환 대상 목록의 단위.
- **레일**: 화면 왼쪽 끝의 세로 바. 기존 역할(팀 전환)에서 새 역할(제품 전환 +
  팀 드롭다운 진입점)로 바뀐다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 제품 전환이 클릭 1번으로 끝난다 (기존 2번: 드롭다운 열기 → 선택).
- **SC-002**: 채널·Boards·Playbooks 어느 화면에서도 팀 전환이 클릭 2번(팀 버튼
  → 팀 선택)으로 끝난다.
- **SC-003**: 레일만 보고 현재 어느 제품에 있는지 식별할 수 있다 — 강조 표시가
  현재 제품과 100% 일치한다.
- **SC-004**: 권한 없는 사용자에게 관리 항목이 노출되는 경우가 0건이다 (기존
  product switcher의 권한 조건과 동일 판정).
- **SC-005**: 플러그인(Boards·Playbooks) 저장소 변경 없이 기존 설치 플러그인
  그대로 전 시나리오가 통과한다.
- **SC-006**: 레일 버튼·팀 드롭다운의 모든 상호작용 요소가 보조기술 이름을
  가진다 (자동 접근성 검사에서 이름 없는 버튼 0건).

## Assumptions

- 브레인스토밍에서 확정: ① product switcher는 제거하고 관리 메뉴는 팀명
  드롭다운으로 이전 ② 팀 전환은 팀명 드롭다운 통합(+ 제품 화면용 레일 팀 버튼)
  ③ 레일은 기능 버튼 레일로 전환.
- 플러그인 수정 없음은 사전 검토로 확인했다: Boards·Playbooks 모두 제품
  등록(아이콘·이름·진입 주소)을 이미 제공하고, 제품 화면에서 레일을 표시하는
  설정이며, 팀 컨텍스트는 본체의 현재 팀을 따른다(Boards는 양방향 동기화,
  Playbooks는 본체 팀 상태를 직접 읽음).
- 현재 제품명 브랜딩(상단 좌측 로고 텍스트)은 product switcher와 함께 제거한다.
  현재 위치 식별은 레일 강조가 담당한다.
- 팀 레일의 드래그 정렬 UI는 제거하고, 저장된 정렬 순서는 드롭다운 목록
  정렬에 계속 쓴다.
- 모바일 전용 레이아웃·데스크톱 앱 전용 동작은 기존 분기를 그대로 두며 이번
  범위에서 새로 설계하지 않는다.
- 014-slack-design-benchmark의 "레이아웃 골격 유지" 전제는 이 기능으로
  갱신된다 — 레일의 역할 재정의가 공식 방향이다.
