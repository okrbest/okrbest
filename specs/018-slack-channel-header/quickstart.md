# Quickstart: Slack식 채널 헤더 재구성 — 종단 검증

**Date**: 2026-10-09 | **Plan**: [plan.md](./plan.md) | **Contract**: [contracts/channel-header-ui.md](./contracts/channel-header-ui.md)

완료 판정은 이 문서의 실주행 결과와 SC-001~SC-006 실측으로 한다.

## 준비 (선행 조건 포함)

```bash
# 0) 의존성 재설치 — React Bootstrap 업그레이드 이후 필수 (research R6)
cd webapp && npm ci

# 1) 서버 (DB 비번이 다르면 .env 로드 또는 MM_SQLSETTINGS_DATASOURCE 오버라이드)
cd ../server && set -a; . ./.env; set +a; make run-server

# 2) 웹앱 watcher
cd ../webapp && make run
```

- 계정: 일반 사용자 1(고정 메시지·파일·북마크가 있는 채널 포함), 멤버 4명
  이상 채널 1곳.
- 북마크 기능이 켜진 서버 설정.

## 시나리오 1 — 탭 줄 (SC-001·SC-003, US1)

1. 채널 진입 → 채널명 아래 [메시지·파일·북마크·고정] 탭 줄, 메시지 활성.
2. 고정 메시지가 있는 채널에서 고정 탭에 개수 배지 확인.
3. 파일 탭 클릭 → 파일 패널 열림 + 파일 탭 활성 (1클릭, SC-001).
4. 패널의 닫기(X) 클릭 → 패널 닫힘 + **탭 활성이 메시지로 복귀** (SC-003).
5. 고정 탭 클릭 → 고정 패널 + 활성. 고정 탭 재클릭 → 닫힘(토글).
6. 스레드를 열어 둔 상태 → 어떤 탭도 활성 아님 확인.
7. 북마크 탭 클릭 → 북마크 바 접힘(탭 비활성). 재클릭 → 펼침. 새로고침 후
   접힘 상태 유지(preference 저장) 확인.
8. 북마크 기능이 꺼진 서버(또는 설정 끄기) → 북마크 탭 미노출.

## 시나리오 2 — 우측 아이콘 (SC-002·SC-004, US2)

1. 멤버 N명 채널에서 아바타 ≤3명+N 표시가 실제 멤버 수와 일치 (SC-004).
2. 스택 클릭 → 기존 멤버 패널 열림.
3. 알림벨 클릭 → 뮤트 + 빗금 벨 (1클릭, SC-002). 채널 메뉴의 뮤트 항목
   상태와 일치 확인. 재클릭 → 해제.
4. ⋮ 클릭 → 채널명 ▾와 동일한 채널 메뉴. 두 진입점 모두 동작.
5. 기존 파일·고정 아이콘이 우측에 없는지 확인.

## 시나리오 3 — DM/GM·기존 기능 보존 (SC-006, FR-009)

1. DM 진입 → 탭 줄 동작, 스택은 상대 아바타, 상태 표시 유지.
2. 즐겨찾기 ☆·채널명 ▾·설명·복사/정보 등 기존 좌측 요소 변화 없음.
3. 북마크 바 자체 기능(항목 메뉴·추가) 변화 없음.

## 시나리오 4 — 접근성 (SC-005)

- 탭 줄: tablist/tab 시맨틱 + 선택 상태가 보조기술에 노출.
- 스택·벨·⋮: 이름 있는 버튼(벨은 뮤트 상태 포함). 접근성 트리 또는
  Playwright snapshot으로 이름 없는 버튼 0건 확인.
