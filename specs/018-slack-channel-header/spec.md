# Feature Specification: Slack식 채널 헤더 재구성

**Feature Branch**: `018-slack-channel-header`

**Created**: 2026-10-09

**Status**: Draft

**Input**: User description: "슬랙 채널 상단 아이콘 배치를 벤치마킹해 채널 기능에 더 직관적으로 접근할 수 있도록 아이콘 노출과 배치를 바꾼다 — 채널명 아래 탭 줄(메시지·파일·북마크·고정) 신설, 우측은 멤버 아바타 스택·알림벨·더보기로 재구성."

## 배경

지금 채널 화면에서 파일·고정 메시지·멤버는 헤더 우측에 라벨 없는 아이콘으로
몰려 있고, 채널 알림(뮤트)은 채널명 드롭다운 속에 숨어 있다. 어떤 아이콘이
무엇인지 호버해 봐야 알고, 자주 쓰는 기능일수록 더 많이 클릭해야 한다.

Slack은 같은 기능을 두 층으로 나눈다 — 채널명 아래 **라벨 있는 탭 줄**
(메시지·파일·북마크·고정)이 콘텐츠 전환을, 우측의 **멤버 아바타 스택·알림·
더보기**가 채널 운영을 맡는다. 이 구조를 벤치마킹하되, 탭의 목적지는 이
제품의 기존 우측 패널(RHS)과 북마크 바를 재사용한다 — 새 화면을 만들지 않고
진입점만 직관적으로 바꾼다.

[014-slack-design-benchmark](../014-slack-design-benchmark/spec.md)의 색·타이포
체계를 따르며, [017-slack-nav-rail](../017-slack-nav-rail/spec.md)이 좌측
네비게이션에 적용한 것과 같은 Slack 문법을 채널 헤더로 확장하는 작업이다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 탭 줄로 채널 콘텐츠를 오간다 (Priority: P1)

사용자가 채널에 들어오면 채널명 아래 탭 줄이 보인다 — **메시지**(활성),
**파일**, **북마크**, **고정**(고정 개수 배지). 파일 탭을 누르면 채널 파일
패널이 열리고 탭이 활성으로 바뀐다. 고정 탭도 같은 방식. 북마크 탭은 채널
북마크 바를 펼치고 접는다. 메시지 탭을 누르면 열린 패널이 닫히고 대화로
돌아온다.

**Why this priority**: 이 기능의 핵심 가치다. 라벨 있는 탭이 "이 채널에 무엇이
있는지"를 상시 노출해 접근을 1클릭으로 만든다.

**Independent Test**: 채널에서 탭 4개의 렌더·클릭 전환·활성 표시를 확인하고,
패널을 다른 경로(패널의 닫기 버튼)로 닫았을 때 탭 활성이 메시지로 돌아오는지
확인한다.

**Acceptance Scenarios**:

1. **Given** 채널 화면이다, **When** 헤더를 본다, **Then** 채널명 아래
   [메시지·파일·북마크·고정] 탭 줄이 보이고 메시지가 활성이다.
2. **Given** 고정 메시지가 3건 있다, **When** 탭 줄을 본다, **Then** 고정 탭에
   3 배지가 보인다.
3. **Given** 메시지 탭이 활성이다, **When** 파일 탭을 누른다, **Then** 채널
   파일 패널이 열리고 파일 탭이 활성으로 바뀐다.
4. **Given** 파일 패널이 열려 있다, **When** 패널의 닫기(X)를 누른다,
   **Then** 패널이 닫히고 탭 활성이 메시지로 돌아온다 (탭과 패널 상태가 항상
   일치한다).
5. **Given** 북마크 바가 펼쳐져 있다, **When** 북마크 탭을 누른다, **Then**
   바가 접히고 탭 활성이 해제된다.
6. **Given** 메시지 탭이 활성이고 패널이 모두 닫혀 있다, **When** 메시지 탭을
   누른다, **Then** 아무 일도 일어나지 않는다 (오동작 없음).

---

### User Story 2 - 우측 아이콘으로 채널을 운영한다 (Priority: P2)

헤더 우측에 멤버 **아바타 스택**(겹친 아바타 3명 + 전체 인원수), **알림벨**,
**더보기(⋮)**가 보인다. 아바타 스택을 누르면 멤버 패널이 열린다. 알림벨을
누르면 채널 뮤트가 토글되고, 뮤트 상태면 빗금 벨로 바뀐다. 더보기를 누르면
채널명 드롭다운과 같은 채널 메뉴가 열린다.

**Why this priority**: 탭 줄(US1)과 독립적으로 가치가 있다 — 멤버 확인과 알림
끄기를 라벨·그림으로 드러낸다. US1 없이도 배포 가능하다.

**Independent Test**: 멤버 5명 채널에서 아바타 3명+숫자 5 표시, 클릭 시 멤버
패널, 벨 클릭으로 뮤트↔해제 토글과 아이콘 변화, ⋮ 클릭으로 채널 메뉴 오픈을
확인한다.

**Acceptance Scenarios**:

1. **Given** 멤버 18명 채널이다, **When** 헤더 우측을 본다, **Then** 아바타
   3명이 겹쳐 보이고 옆에 18이 표시된다.
2. **Given** 아바타 스택이 보인다, **When** 클릭한다, **Then** 기존 멤버
   패널이 열린다 (보류 가입 요청 표시 등 기존 상태 그대로).
3. **Given** 채널이 뮤트 아님이다, **When** 알림벨을 누른다, **Then** 채널이
   뮤트되고 벨이 빗금 모양으로 바뀐다. 다시 누르면 해제된다.
4. **Given** 헤더 우측이다, **When** ⋮를 누른다, **Then** 채널명 드롭다운과
   동일한 채널 메뉴가 열린다. 채널명 옆 ▾ 드롭다운도 그대로 동작한다.
5. **Given** 기존 헤더의 파일·고정 아이콘 자리다, **When** 헤더를 본다,
   **Then** 그 아이콘들은 더 이상 없다 (탭 줄로 이동).

---

### Edge Cases

- 고정 0건이면 고정 탭에 배지가 없다 (탭 자체는 보인다).
- 채널 북마크 기능이 서버 설정으로 꺼져 있으면 북마크 탭이 나타나지 않는다.
- DM·그룹 DM에서도 탭 줄과 우측 구성이 동작한다 — 멤버 아바타 스택은 DM 상대
  (또는 GM 구성원)로, 기존 DM 헤더 특수 표시(상태·커스텀 상태)는 유지한다.
- 보관(archived) 채널에서는 쓰기성 동작(뮤트 토글)이 기존 보관 채널 규칙을
  따른다 — 기존에 숨던 것은 숨는다.
- 좁은 화면에서 탭 줄이 넘치면 가로 스크롤 없이 우선순위대로 남는다(메시지·
  고정 우선). 모바일 전용 레이아웃은 기존 분기 그대로 두고 이번 범위 밖이다.
- 멤버가 3명 미만이면 있는 만큼만 겹쳐 보인다.
- 다른 패널(스레드·검색 결과 등)이 열려 있을 때 탭 활성은 메시지가 아니라
  "해당 탭 없음" 상태다 — 파일·고정 탭은 자기 패널이 열렸을 때만 활성이고,
  메시지 탭은 패널이 모두 닫혔을 때 활성이다. 스레드 등 제3의 패널이 열려
  있으면 어떤 탭도 활성이 아니다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 채널 헤더는 채널명 줄 아래에 탭 줄을 보여준다 — 메시지·파일·
  (북마크 기능 활성 시) 북마크·고정 순서. 각 탭은 아이콘과 한국어/영어 라벨을
  가진다.
- **FR-002**: 파일 탭은 채널 파일 패널을, 고정 탭은 고정 메시지 패널을 연다.
  이미 열려 있으면 닫는다(토글). 고정 탭에는 고정 개수 배지가 붙는다(0이면
  배지 없음).
- **FR-003**: 북마크 탭은 채널 북마크 바를 펼치고 접는다. 북마크 기능이 꺼진
  서버에서는 탭이 나타나지 않는다.
- **FR-004**: 메시지 탭은 열린 채널 콘텐츠 패널(파일·고정)을 닫고 대화로
  돌아온다. 패널이 없으면 아무 동작도 하지 않는다.
- **FR-005**: 탭 활성 표시는 패널·바의 실제 상태에서 파생된다. 패널을 어떤
  경로로 닫아도 탭 표시가 함께 돌아온다 — 탭과 상태가 어긋나는 경우가 없다.
- **FR-006**: 헤더 우측의 기존 파일·고정 아이콘 버튼은 제거된다 (탭 줄이
  대체). 멤버 버튼은 아바타 스택(겹친 아바타 최대 3명 + 전체 인원수)으로
  바뀌며 클릭 동작·보류 가입 요청 표시 등 기존 기능은 유지된다.
- **FR-007**: 알림벨이 헤더 우측에 상시 노출된다. 클릭하면 채널 뮤트가
  토글되고 뮤트 상태가 아이콘(빗금 벨)으로 구분된다. 기존 채널 메뉴의 뮤트
  항목도 그대로 동작하며 두 경로의 상태는 일치한다.
- **FR-008**: 더보기(⋮) 버튼은 채널명 드롭다운과 동일한 채널 메뉴를 연다.
  채널명 ▾ 진입점은 유지된다 (같은 메뉴, 두 진입점).
- **FR-009**: DM·그룹 DM에서도 같은 구조가 동작하며, DM 헤더의 기존 특수
  표시(상대 상태 등)는 유지된다.
- **FR-010**: 탭과 우측 버튼은 보조기술이 읽을 수 있는 이름을 가지며, 탭 줄은
  탭 시맨틱(현재 탭 식별 포함)을 제공한다. 새 문구는 한국어·영어로 제공한다.
- **FR-011**: 채널 내 검색 아이콘과 허들(통화) 버튼은 이번 범위에 넣지 않는다.

### Key Entities

- **채널 콘텐츠 패널(RHS)**: 파일·고정 메시지·멤버를 보여주는 기존 우측 패널.
  탭의 목적지이며 이 기능은 새 패널을 만들지 않는다.
- **채널 북마크 바**: 헤더 아래 기존 바. 북마크 탭이 펼침/접기를 제어한다.
- **탭 상태**: 저장되지 않는 파생 값 — 패널·바의 현재 상태가 곧 탭 활성이다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 파일·고정·북마크 접근이 라벨 있는 탭 1클릭으로 끝난다 (기존:
  라벨 없는 아이콘 식별 후 클릭, 또는 메뉴 탐색).
- **SC-002**: 채널 뮤트 전환이 헤더에서 1클릭으로 끝난다 (기존: 드롭다운 열기
  → 항목 선택 2클릭).
- **SC-003**: 탭 활성 표시와 패널 실제 상태의 불일치가 0건이다 — 어떤 경로로
  패널을 여닫아도 탭이 따라온다.
- **SC-004**: 헤더만 보고 채널 멤버 규모를 알 수 있다 — 아바타 스택+인원수가
  실제 멤버 수와 100% 일치한다.
- **SC-005**: 탭·우측 버튼의 모든 상호작용 요소가 보조기술 이름을 가진다
  (이름 없는 버튼 0건).
- **SC-006**: 기존 기능(파일·고정·멤버 패널, 뮤트, 채널 메뉴, 북마크 바)의
  동작 변화가 0건이다 — 진입점만 바뀐다.

## Assumptions

- 브레인스토밍에서 확정: 탭은 본문 전환이 아니라 기존 패널(RHS)·북마크 바
  재배선이다. 우측 구성은 아바타 스택·알림벨·⋮이고, 채널 내 검색(전역 검색과
  중복)·허들(통화 플러그인 영역)은 제외한다.
- ⋮는 신규 메뉴를 만들지 않고 기존 채널 메뉴의 두 번째 진입점이다.
- 즐겨찾기(☆)·채널명·설명 등 헤더 좌측 기존 요소는 자리 유지한다.
- 모바일 전용 레이아웃·브라우저 좁은 폭의 반응형 세부는 기존 분기를 따르고
  새로 설계하지 않는다.
- 014 벤치마크의 색·타이포 체계를 그대로 쓴다 (새 팔레트 없음).
- 구현 착수 전에 웹앱 의존성 재설치가 선행되어야 한다 — 직전 업그레이드
  (React Bootstrap) 이후 재설치 누락으로 현재 로컬 화면이 뜨지 않는 상태다
  (plan.md에서 다룬다).
