# 완전성 대조표: 후속 영역 필요 수치 ↔ 기준표 (SC-001)

로드맵 ②헤더·툴바 ③사이드바 ④메시지가 쓸 레이아웃 수치 유형을 나열하고
기준표 토큰을 대응시킨다. 빈칸이 없으면 SC-001 통과다. 값을 **바꾸는** 결정
(예: 헤더 좌 패딩 12→16)은 각 영역 기능의 몫 — 여기서는 "고를 단계가
있는가"만 본다.

## 판정

세 영역 27행 전부 대응 토큰 있음 — **빈칸 0 (SC-001 통과)**. 아바타 크기
(36/20)는 컴포넌트 고유 치수로 보고 토큰화하지 않는다 — ④에서 컴포넌트
상수로 다루며, measurements.md에 실측(36·20)이 남아 있다.
