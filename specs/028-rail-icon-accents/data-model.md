# Data Model: 레일 제품 아이콘 액센트 색상 상태

**Date**: 2026-10-14 | **Plan**: [plan.md](./plan.md)

서버 데이터·스토어 엔티티 변경은 없다. 이 기능의 "모델"은 알약의 시각
상태 기계다.

## 시각 상태 기계

입력 2축에서 상태가 파생된다.

- **선택 여부**: 라우팅에서 오는 `active` prop (`.rail-product-button.active`)
- **테마 모드**: `body[data-theme-type]` — `'Slate'`(라이트) / `'Onyx'`(다크)

| 상태 (두 테마 공용) | 알약 배경 | 아이콘 색 | 획 | 라벨 |
|---|---|---|---|---|
| 비선택 | `#0866FF` 솔리드 | `#fff` | 0.6 | 600 |
| 비선택 hover/focus | `#075EEB` 솔리드 | `#fff` | 0.6 | 600 |
| 선택 | `#4F46E5` 솔리드 | `#fff` | 0.8 | 700 |

색은 테마와 무관한 고정값이다 — 2차 확정 경위와 대비 수치는
[research R2-v3](./research.md). 다크 전용 분기는 없다.

공통 불변값: 알약 36×36, `border-radius: var(--radius-m)`(8px), 글리프
28×28, 버튼 전체 opacity 없음(제거), transition 기존 유지.

## 상태 전이

- 제품 이동(클릭/키보드): `active`가 옮겨 가며 솔리드 표시도 즉시 이동
  (FR-002, SC-004). 전이는 라우팅이 소유 — 이 기능은 표시만 바꾼다.
- 테마 전환(토글·시스템 추종·초기 로드): 알약 색은 공용 고정값이라 전환과
  무관하게 유효하다 (FR-008). `applyTheme()`의 `body[data-theme-type]`
  갱신은 유지되지만(계약 C1) 현재 레일 스타일은 이를 소비하지 않는다.

## 검증 규칙 (요구 추적)

- 흰 아이콘 대비 4.5:1 이상 — FR-009 (계산: 비선택 4.82:1, hover 5.51:1,
  선택 6.29:1, [research R2-v3](./research.md)).
- `data-theme-type` 값은 테마의 `type` 문자열 그대로 — 현재 레일 스타일은
  소비하지 않으며, 어떤 값이 와도 공용 고정색이 적용된다.
