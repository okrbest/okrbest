# Feature Specification: 레일 제품 아이콘 액센트 색상 상태

**Feature Branch**: `028-rail-icon-accents`

**Created**: 2026-10-14

**Status**: Draft

**Input**: User description: "좌측 채널, 보드, 플레이북 등의 선택 아이콘의 배경을 평상시에는 Accents Blue 계열 배경색으로, 선택 후에는 Accents Indigo 등의 배경으로. 아이콘의 크기는 배경에 꽉 차보이게 키우고 굵게 표시(배경 모서리는 라운딩 처리). 다크모드 상태에서는 선택 후에 다크모드에 어울리는 배경색과 아이콘 색 사용" (브레인스토밍으로 확정: 평상시 파랑 틴트, 선택 시 솔리드)

## 현재 동작

좌측 레일의 제품 버튼(채널·보드·플레이북)은 36×36 라운딩 알약 안에
아이콘을 담는다. 평상시 알약은 배경이 없고 버튼 전체가 반투명(73%)으로
흐리게 보인다. 선택된 제품은 알약에 회색 틴트(사이드바 글자색 16%)가
깔리고 라벨이 굵어진다. 선택/비선택의 색 차이가 약해 지금 어느 제품에
있는지 한눈에 읽히지 않고, 아이콘(24px)이 알약(36px) 안에서 작아 보인다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 선택된 제품이 한눈에 보인다 (Priority: P1)

사용자가 채널·보드·플레이북 중 한 제품에 들어가 있으면, 레일에서 그
제품의 아이콘 알약만 인디고 솔리드 배경 + 흰 아이콘으로 채워져 현재
위치가 즉시 읽힌다.

**Why this priority**: 이 기능의 핵심 요구다. 현재의 회색 틴트는 선택
상태 식별이 약하다.

**Independent Test**: 채널 화면에 들어간 상태에서 레일을 보고, 채널
알약만 인디고 솔리드 + 흰 아이콘이고 나머지는 파랑 틴트인지 확인한다.

**Acceptance Scenarios**:

1. **Given** 라이트 모드에서 채널 제품을 보고 있다,
   **When** 레일을 본다,
   **Then** 채널 알약은 비비드 인디고(#4F46E5) 솔리드 배경에 흰 아이콘,
   라벨은 굵게 표시되고, 보드·플레이북 알약은 비비드 파랑(#0866FF) 솔리드다.
2. **Given** 채널이 선택된 상태다,
   **When** 플레이북 버튼을 누른다,
   **Then** 인디고 솔리드가 플레이북 알약으로 옮겨 가고 채널 알약은
   파랑 솔리드로 돌아간다.

---

### User Story 2 - 평상시에도 제품 영역이 구분된다 (Priority: P2)

선택되지 않은 제품 버튼도 비비드 파랑 솔리드 배경과 흰 아이콘을
가져, 레일의 제품 영역이 팀 버튼·기타 영역과 시각적으로 구분된다.

**Why this priority**: 요청의 절반("평상시 Accents Blue 계열 배경")이다.
다만 US1의 선택 식별이 성립해야 대비 효과가 산다.

**Independent Test**: 어느 제품도 호버하지 않은 상태에서 비선택 알약에
비비드 파랑 솔리드 배경과 흰 아이콘이 보이는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 레일에 제품 버튼이 표시돼 있다,
   **When** 아무 조작 없이 레일을 본다,
   **Then** 비선택 알약마다 비비드 파랑(#0866FF) 솔리드 배경이 깔리고 흰
   아이콘이 또렷하게(반투명 뿌연 처리 없이) 보인다.
2. **Given** 비선택 알약이 파랑 솔리드 상태다,
   **When** 포인터를 올린다,
   **Then** 파랑이 살짝 어두워져 호버 반응이 보인다.

---

### User Story 3 - 다크모드에서도 선택 상태가 또렷하다 (Priority: P3)

다크 모드에서도 알약이 어두운 레일 위에서 묻히지 않고 선택/비선택이
또렷이 구분된다. (2차 확정: 비비드 공용색 #0866FF·#4F46E5가 어두운 레일
위에서도 선명해 다크 전용 색 분기 없이 충족한다.)

**Why this priority**: 요청에 명시된 조건이지만 US1이 먼저 성립해야 한다.

**Independent Test**: 테마 토글로 다크 모드로 전환한 뒤 선택 알약
(#4F46E5)·비선택 알약(#0866FF)이 어두운 레일과 또렷이 구분되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 채널이 선택된 라이트 모드 상태다,
   **When** 테마를 다크 모드로 전환한다,
   **Then** 알약 색은 그대로 유효하고(#4F46E5 솔리드 + 흰 아이콘), 어두운
   레일 배경과 또렷이 구분되며 전환 끊김이 없다.
2. **Given** 다크 모드다,
   **When** 비선택 알약을 본다,
   **Then** 비비드 파랑 솔리드와 흰 아이콘이 어두운 레일 위에서 식별된다.

---

### Edge Cases

- 보드·플레이북 플러그인이 꺼져 제품 버튼이 1~2개만 있으면? 남은 버튼에
  같은 규칙이 적용된다 (버튼 수와 무관).
- 키보드 포커스가 올라가면? 호버와 같은 수준의 시각 반응을 주고, 포커스
  표시(아웃라인 등)가 가려지지 않는다.
- 시스템 테마 모드에서 OS가 라이트↔다크를 바꾸면? 전환 즉시 선택 알약
  색이 해당 모드 색으로 따라간다 (새로고침 불필요).
- 아이콘이 제품 등록값에 따라 글리프가 아니라 임의 노드로 올 때도? 알약
  크기·배경 규칙은 동일하게 적용된다.
- 팀 전환 버튼(팀 아바타)은? 이 기능의 범위 밖이다 — 기존 표시를 유지한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 레일 제품 버튼(채널·보드·플레이북)의 아이콘 알약은 평상시
  비비드 파랑(#0866FF — 사용자 레퍼런스 이미지 실측색) 솔리드 배경 + 흰
  아이콘을 표시한다. (1차 구현의 틴트 + 테마 파랑은 사용자 피드백 "배경색
  느낌이 완전 다르다"로 2026-10-14 폐기.)
- **FR-002**: 선택된 제품의 알약은 비비드 인디고(#4F46E5) 솔리드 + 흰
  아이콘으로 표시한다. 두 색 모두 어두운 레일에서도 선명해 라이트·다크
  공용이다.
- **FR-003**: 알약 배경 모서리는 기존 라운딩(radius 8)을 유지한다.
- **FR-004**: 아이콘 글리프는 알약에 꽉 차 보이게 기존(24px)보다 키우고
  (28px), 선택 시 획 보강으로 더 굵게 보인다. 획 보강은 글리프 안쪽
  투명부를 잠식하지 않는 수준을 지킨다.
- **FR-005**: 버튼 전체를 흐리게 만드는 반투명 처리(73%)를 걷어내 틴트·
  솔리드 색이 설계값 그대로 보인다. 라벨의 기존 명도 위계는 유지한다.
- **FR-006**: 호버·키보드 포커스 시 비선택 알약의 파랑이 살짝 어두워진다
  (#0866FF→#075EEB). 선택 알약은 솔리드를 유지한다.
- **FR-007**: 선택 알약의 라벨은 기존대로 굵게(700) 표시한다.
- **FR-008**: 알약 색은 두 모드 공용 솔리드라 라이트·다크 전환(수동 토글·
  시스템 추종 모두)과 무관하게 항상 유효하다. 전환 시 끊김·잔상이 없다.
- **FR-009**: 두 모드 모두에서 선택 알약의 흰 아이콘은 배경과 WCAG AA
  수준(4.5:1 이상)의 대비를 유지한다.
- **FR-010**: 팀 전환 버튼과 레일의 다른 요소(테마 토글·프로필 등)의
  표시는 바뀌지 않는다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 라이트 모드에서 선택 제품의 알약이 인디고 솔리드 + 흰
  아이콘으로, 비선택 2개가 파랑 틴트로 보인다 (실주행 스크린샷으로 확인).
- **SC-002**: 다크 모드 전환 직후 선택 알약 배경이 밝은 인디고로 바뀌어
  어두운 레일과 구분된다 (전환 전후 스크린샷 비교).
- **SC-003**: 선택 알약의 흰 아이콘 대비가 라이트(#28427B 위)·다크
  (#32539A 위) 모두 4.5:1 이상으로 계측된다.
- **SC-004**: 제품 간 이동 시 솔리드 표시가 클릭 1회로 즉시 이동한 제품
  알약으로 옮겨 간다 (지연·잔상 없음).
- **SC-005**: 아이콘 글리프가 기존 대비 커져(24→28px) 알약 면적 대비
  글리프 비율이 약 78%가 된다 (스타일 계측으로 확인).

## Assumptions

- "Accents Blue/Indigo"의 정본은 사용자 레퍼런스 이미지다 — Blue #0866FF
  (이미지 실측), Indigo #4F46E5(같은 채도감으로 사용자가 선택). 두 색은
  테마와 무관한 고정값이다. (1차 해석 — 틴트 + 저장소 팔레트 변수 — 는
  사용자 피드백으로 폐기, 2026-10-14 2차 확정.)
- 평상시 표시는 2차 확정에서 **솔리드**다 (처음 요청으로 복귀).
- 라이트=Slate, 다크=Onyx 고정 매핑(spec 024)을 전제로 한다. 그 외 테마는
  고려하지 않는다.
- 팀 전환 버튼·테마 토글 등 레일의 비제품 요소는 범위 밖이다.
- 라벨 글자 색·크기 체계는 기존(11px, 비선택 600/선택 700)을 유지한다.
